02 — Get started

1. Link the stylesheet and the core script

Copy the css and js folders into your site. Link one stylesheet; it pulls in everything else. Add a component’s script only if you use that component.

2. Start from the page frame

The background, the cap, the header and a column of content panels. See Layout and grid.

3. Copy components from these pages

Every example has its code underneath, with a Copy button. Change tokens in your own stylesheet, after jewel.css, rather than editing the system.

03 — Principles

What Jewel stands for

  • Restraint. Hairlines, one typeface, almost no shadow. The gradient is the only loud thing.
  • Tokens first. Components read colours, sizes and timings from tokens, never raw values.
  • Readable everywhere. Every text colour meets WCAG AA on glass and on solid; every control is 44px to touch.
  • HTML first. Native elements, no framework and no build step. Scripts add behaviour; the content works without them.
