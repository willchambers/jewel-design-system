Text field

Text fields are hairline boxes with an uppercase label above. On focus the box turns accent and doubles to 2px; on an error it turns red and says what to fix.

CSS
css/components/field.css, css/components/input.css
JS
js/components/form.js

01 — Variants

Text input

A label, the input, and an optional hint. .field__req marks a required field; .field__optional marks an optional one.

Shown on your profile.

With a counter

Add maxlength and data-counter and the field counts down as people type.

A few words.

Text area

Grows with its content as people type.

Select

The native select, with a hairline chevron. Best for picking one of a few known values in a form.

02 — States

Filled, error, disabled and suggested

Click into a field to see focus. An error names the problem and how to fix it. A suggested value (for example, alt text drafted by an assistant) is marked until someone edits it.

Add a title before posting.

03 — Usage

Use it for

  • A visible label on every field. Placeholders are examples, not labels.
  • Hints for format and limits, before people make a mistake.
  • Error messages that say what to do: “Add a title before posting”.

Avoid

  • Placeholder text as the only label.
  • Disabling a field without saying why.
  • A select with only two options. Use radio buttons.

04 — Accessibility

Notes

  • Every input has a <label for>. Hints, counters and errors are linked with aria-describedby.
  • Errors set aria-invalid="true"; form.js moves focus to the first error on submit.
  • Field edges are 40% white (3.25:1), above the 3:1 that input edges need. Fields are 44px tall.
