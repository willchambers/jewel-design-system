Tooltip

A short hint for a control, shown on hover and keyboard focus. A light box with dark text and a small pointer, so it stands out against the dark panels.

02 — Usage

Use it for

  • Naming an icon button’s action.
  • Showing the full text of a shortened value.
  • A keyboard shortcut next to an action.

Avoid

  • Anything important. Touch screens have no hover, so it may never be seen.
  • Links, buttons or anything else to click inside it.
  • More than a few words. Put longer help in the page.

03 — Accessibility

Notes

  • The bubble is linked with aria-describedby, so screen readers read it with the control even while it’s hidden.
  • It opens on keyboard focus as well as hover, stays open while the pointer is over it, and Esc closes it (WCAG 1.4.13).
  • It’s a hint, not a label: an icon button still needs aria-label.
  • Dark text on the light box is 16.12:1.
