Progress

How far along a task is: a thin bar, a label and a value. It’s a native progress element, so screen readers announce it.

02 — Usage

Use it for

  • Uploads, imports and anything that takes more than a couple of seconds.
  • Set the value from a script: bar.value = 72.

Avoid

  • Short waits. A busy button is enough.
  • Showing a score or a quota. That’s a stat.
