Drop zone

Pick one photo by dragging it in or tapping to browse. It shows a preview with the file’s name, size and dimensions, and offers Replace and Remove.

CSS
css/components/dropzone.css
JS
js/components/dropzone.js (after form.js)

01 — Example

One photo

Drop an image here or browse. On phones the native picker offers the library and the camera.

02 — Behavior

Script

NameDetail
data-max-sizeThe largest file, in MB. Bigger files show an error.
jewel:filechangeDetail { file, source }, where source is user, api or clear.
el.jewelDropzone.setFile(blob, name), .getFile(), .clear().

03 — Usage

Use it for

  • Uploading one photo, as in the post form.

Avoid

  • Several files at once. It takes one.
  • Documents. It’s built around image previews.

04 — Accessibility

Notes

  • It’s a real file input with a label, so keyboard and screen reader users browse as normal.
  • The preview’s name, size and dimensions are text, and errors are announced like any field error.
