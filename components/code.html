Code snippet

A block of code with its language and a Copy button, for anything people should paste. Inline code and keyboard keys are styled too.

CSS
css/components/code.css
JS
js/components/code.js

01 — Variants

Block

The Copy button says “Copied” for two seconds, and screen readers hear it too. Every example on this site uses it.

Wrapped

.code--wrap wraps long lines instead of scrolling. .code--tall scrolls past about 20 lines.

Inline

Inline <code> and <kbd> in running text.

Link css/jewel.css, then press / to search.

02 — Usage

Use it for

  • Anything people should copy exactly.
  • Escaping <, > and & in the markup.

Avoid

  • Syntax colors outside the text tokens. If you add a highlighter, map it to default, muted and accent only.

03 — Accessibility

Notes

  • tabindex="0" on the <pre> lets keyboard users scroll a long line.
  • On plain http pages, copying falls back to a selection copy.
