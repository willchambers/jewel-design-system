Lightbox

A full-screen viewer for photos. Tap a thumbnail to open it; arrows, swipes and Esc work, and focus goes back to the photo that opened it.

CSS
css/components/lightbox.css
JS
js/components/lightbox.js

01 — Example

Gallery

Any container of a[data-lightbox-item] links. Each link points at the full image, so it still works without a script. data-caption is the first line; data-description adds a quieter second line.

02 — Behavior

Script

NameDetail
Keyboard← → move between photos, Esc closes. Focus returns to the thumbnail.
TouchSwipe to move, and the viewer clears the notch and home indicator.
FilteringPhotos that are hidden, or inside a hidden parent, are skipped, so it works with a filter.

03 — Usage

Use it for

  • Galleries and photo walls where people want to see each photo large.

Avoid

  • A single image that’s already large. Let it be.
  • Videos. Use the video figure.

04 — Accessibility

Notes

  • Every thumbnail needs real alt text.
  • The viewer is a native <dialog>; the caption is read when each photo opens.
