Data table

Rows of records people scan, sort and select: hairline rows, small uppercase headers, and numbers right-aligned so they line up.

01 — Variants

Sortable and selectable

Click a header to sort. data-select adds checkboxes and a select-all. On phones, .table--stack turns each row into label and value pairs.

02 — Behaviour

Script

NameDetail
Sortingth[data-sort] sorts as text, number or date. A cell’s data-value or <time datetime> sorts in place of its text. Event: jewel:sort.
Selectiondata-select on the wrap. Selected rows get aria-selected="true". Event: jewel:selectionchange; API wrap.jewelTable.selected().
SizeWide tables scroll sideways inside .table-wrap. .table-wrap--tall fixes the height with a sticky header.
Rows as links.table__link on a row’s main link makes the whole row clickable.

03 — Usage

Use it for

  • Records people compare across several columns.
  • .is-num on number columns, so digits line up.

Avoid

  • Layout. Use the grid.
  • Two columns of facts. Use a meta list.
  • A chart’s data. Charts keep their own table view.

04 — Accessibility

Notes

  • A caption names the table. Headers use scope.
  • Sortable headers are buttons that announce the sort direction (aria-sort).
