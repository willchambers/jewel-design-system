Filter

A row of tag buttons that shows only the items that match. It reads tags from the items themselves and announces how many are showing.

CSS
css/components/filter.css
JS
js/components/filter.js

01 — Variants

Filter a list

Items in the target carry data-tags. data-filter="*" shows everything.

Scrolling row

.filter--scroll keeps long tag lists on one row that scrolls sideways, out to the panel’s edges.

02 — Behavior

Script

NameDetail
data-filter-targetA selector for the container of items.
data-filter-nounThe word in the announcement: “3 projects”.
LinksOpening the page at #tag=slug, or following such a link, applies that tag.

03 — Usage

Use it for

  • Narrowing a list or gallery by a handful of categories.
  • Up to about a dozen tags; scroll the row past that.

Avoid

  • Searching. Use search.
  • Switching views. Use tabs.

04 — Accessibility

Notes

  • Pressable tags with aria-pressed, in a labeled group.
  • A polite live region announces the count after each change.
