Foundations

The decisions everything else is built on: type, color, space, layout, surfaces and motion. Each one is a set of tokens in css/tokens.css.

01 — All foundations

  • TypographyInter, the type scale, weights, text colors and links.
  • ColorThe Jewel palette and the resolved color tokens components use.
  • Spacing and sizingThe spacing scale, control heights, icon sizes, radii and rules.
  • Layout and gridThe 12-column grid, breakpoints, page structure and stacking order.
  • Panels and surfacesGlass and solid panels, the content panel shape, the knockout and the background.
  • MotionDurations, easing curves and reduced motion.
