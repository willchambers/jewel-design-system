02 — Using them

Markup

Link to an icon in the sprite. It takes the text color, and the stroke comes from .icon.

Sizes

.icon--xs 14px, the default 16px for buttons and fields, .icon--md 22px for header actions, .icon--lg 28px for empty states.

In buttons

An icon button names its action with aria-label; the icon is hidden from screen readers.

03 — Adding an icon

Notes

  • Find the icon on lucide.dev and open its SVG.
  • Copy the elements inside the <svg> into a new <symbol id="name" viewBox="0 0 24 24"> in media/icons.svg. Leave the stroke attributes off; .icon sets them.
  • Lucide is under the ISC license, kept in media/LICENSE-lucide.txt.
  • The sprite loads over http. Opened straight from a file (file://), most browsers block it, so serve the folder or paste the icon’s paths inline.

04 — Accessibility

Notes

  • Decorative icons, and icons next to a word, get aria-hidden="true".
  • An icon that is the only label of a button: put aria-label on the button.
  • A standalone icon that means something (a warning): give the <svg> role="img" and an aria-label.
